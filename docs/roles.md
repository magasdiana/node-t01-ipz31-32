## Прийняті припущення

- Manager має права лише там, де README називає його прямо; решта для нього «ні» («менший рівень доступу», розділ 3).
- Parent бачить лише свою дитину (картка, рахунок, оплати, розклад її групи) і може доповнювати лише додаткові дані дитини (FR-04). Створювати й видаляти дітей він не може (FR-05).
- Parent лише читає оплати: у README «Parent свої» неоднозначно.
- Teacher у PATCH /lessons змінює лише власні заняття (FR-21).
- /settings/prices лише для Admin (розділ 3: змінює ціни, зарплати, харчування).
- /rooms у README не описано; доступ Admin і Manager, як для груп.
- /history лише для Admin: у записах є знижки й дані інших сімей.
