# Test Cases — Kindergarten API

## 1. Загальна інформація

**Проєкт:** Kindergarten API  
**Тип тестування:** автоматизоване та ручне тестування API  
**Інструмент:** Node.js Test Runner (`node:test`)  
**Файл автоматизованих тестів:** `tests/api.test.js`  
**Дата останнього запуску:** 28.10.2026  
**Тривалість виконання:** приблизно 15,3 секунди

### Статуси тестів

- **PASS** — тест успішно пройшов.
- **FAIL** — тест завершився невдало.
- **NOT RUN** — тест ще не виконувався.
- **BLOCKED** — перевірку неможливо завершити через відсутність необхідного функціоналу або залежностей.
- **REVIEW** — результат потрібно додатково звірити з вимогами API.
